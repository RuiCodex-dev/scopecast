# AI disclosure

- **Code and planning:** built with an AI coding agent (Claude Code) using the Devpost Learn Skill Pack
  (`.agents/skills/`, `skills-lock.json`), as the hackathon requires. The planning documents in `devpost/`
  were produced through the skills' scope → PRD → spec → build flow. All code was written for this
  project during the submission period; no pre-existing code was reused.
- **Images:** three marketing photographs (office, bakery, desk) were generated with Google Flow
  (Nano Banana Pro) — see `design/GENERATED_ASSETS.md`. They are used only in the video, its thumbnail and
  the Devpost cover, never inside the app or the README, and never presented as real photos of customers.
- **Video:** product footage is real screen capture of the app. The narration is synthetic speech
  (Microsoft Edge neural TTS). The music is synthesised by `video/make_music.py`. No AI-generated video.
- **Sample data:** the bakery client in the sample project is fictional.
